## Getting Started

1. Open the notebook in Kaggle.
2. Enable the required accelerator and internet access in the notebook settings.
3. Run the setup cells in order.
4. Start Ollama and download or configure the desired model.
5. Use the notebook workflow to run inference and interact with the model.

## Notes

- Kaggle session limits and hardware availability may affect how long a notebook can run.
- Model download time and memory requirements depend on the selected model and Kaggle accelerator.
- Review the notebook configuration before running it with a different model or hardware profile.
